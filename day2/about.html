About QuickNotes

QuickNotes is a lightweight web application designed to help you capture your thoughts instantly. It provides a clean environment for organizing your daily tasks.

How to use QuickNotes

  1. Click the "New Note" button.
  2. Type your thoughts into the editor.
  3. Click save to secure your note.

Features

  • Instant automatic cloud saving
  • Dark mode toggle
  • Tag organization

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Manually save
